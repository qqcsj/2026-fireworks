# 🎆 2026 跨年视觉盛宴 (2026-fireworks)

这是一个基于 HTML5 Canvas 制作的 2026 专属跨年交互网页。

## ✨ 特效亮点
- **🎵 音乐与视觉同步**：点击开启按钮，跨年 BGM 瞬间点燃氛围。
- **💥 粒子物理引擎**：文字由成千上万个彩色发光粒子组成，具有 Q弹的物理聚合效果。
- **🎇 震撼爆炸转场**：3-2-1 倒计时结束后，粒子会像真实炸弹一样向四面八方炸开，再重新聚合成“2026”。
- **🌃 全屏动态烟花**：底层拥有独立运行的烟花系统，不断升空、绽放、拖尾，与表层文字互不干扰。

## 🚀 如何使用
直接通过浏览器打开 `index.html`，点击页面中心的按钮即可体验。

## 🛠️ 技术栈
- 原生 HTML / CSS / JavaScript
- HTML5 Canvas (粒子特效与烟花渲染)
